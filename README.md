# Портфолио разработчика

Адаптивный сайт в тёмном минимализме: интерактивные кейсы, фильтры, мобильное меню и форма для подготовки проектного брифа. Vanilla JavaScript и Vite; шрифты поставляются локально, без сторонних запросов при открытии страницы.

## Запуск

Требуется Node.js 22.12+ или 24+. В облачной среде установлен Node.js 24.

```sh
cd /workspace/portfolio-gpt
npm --cache /tmp/portfolio-npm-cache ci
npm run dev -- --port 5173 --strictPort
```

```sh
npm run build
npm run preview -- --port 4173 --strictPort
npm test
```

Для тестов используется системный Chromium (`/usr/bin/chromium`). На другом компьютере укажите путь в `CHROMIUM_PATH`, либо установите Chromium и настройте `launchOptions.executablePath` в `playwright.config.js`.

## Персонализация

- `src/content.js`: имя, специализация, доступность, реальный публичный email и данные проектов.
- `src/main.js`: тексты разделов, монограмма и иллюстрации концепций.
- `src/style.css`: палитра, композиция, адаптивные состояния.
- `index.html`: заголовок страницы и описание для поисковиков.
- `public/favicon.svg`: знак бренда.

Алекс Мор — демонстрационная персона. Forma, Orbit и Mono — демонстрационные концепции, без заявлений о реальных заказчиках или коммерческих результатах. Перед публикацией замените имя, кейсы, монограмму и метаданные своими.

По умолчанию форма **скачивает текстовый бриф**: данные не отправляются и не сохраняются на сервере. Если заполнить `profile.email`, форма подготовит письмо через `mailto`; отправка останется в почтовом клиенте посетителя. Для серверной отправки потребуется отдельная интеграция.

## Публикация

`npm run build` создаёт папку `dist`. Её можно разместить на любом статическом хостинге. Внешняя база данных, API и секреты для текущей версии не нужны.

Тесты проверяют фильтры, содержимое кейсов, возврат фокуса, валидацию формы, содержимое скачанного брифа, мобильную навигацию, отсутствие горизонтального переполнения и настройку уменьшенной анимации.
